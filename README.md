# Y Direct Editor

Откройте сервис в браузере: [file:///Users/admin/Coding/Direct%20Ya/index.html](file:///Users/admin/Coding/Direct%20Ya/index.html)

**Для пользователей на других компьютерах:** Если путь к файлу `index.html` отличается, замените URL в ссылке выше на соответствующий путь (например `file:///полный/путь/к/директории/index.html`), или запустите локальный сервер (например с помощью `start.command`) и откройте `http://127.0.0.1:5511`.

Инструмент для удобного редактирования и визуализации CSV-файлов объявлений Яндекс Директ.

## Обзор

Проект представляет собой веб-приложение, которое позволяет загружать таблицы в формате CSV, редактировать их в реальном времени, отслеживать лимиты символов для заголовков и описаний, экспортировать красивые отчеты в Excel для согласования с клиентом, а также сохранять изменения обратно в CSV.

## Основные возможности

- **Интерактивная таблица**: Редактирование текстовых полей прямо в браузере.
- **Контроль лимитов символов**:
  - Заголовок 1: до 56 символов.
  - Заголовок 2: до 30 символов.
  - Описание: до 81 символа.
  - Автоматический подсчет использованных символов и отображение остатка лимита.
- **Управление строками**: Возможность дублировать («Копировать») или удалять строки (с подтверждением).
- **Функции поиска и сортировки**: Быстрая фильтрация данных и сортировка по любому столбцу.
- **Быстрое копирование**: Отдельные кнопки для копирования содержимого ячеек в один клик.
- **Экспорт для клиента (Excel / XLSX)**: Создание красиво оформленного Excel-файла с автоматической настройкой ширины колонок, группировкой и цветовым выделением для отправки клиентам.
- **Живое обновление (Live Update)**: При использовании Node.js сервера изменения в CSV-файле на диске автоматически отображаются в интерфейсе через Server-Sent Events (SSE).
- **Современный UI**: Темная тема, эффекты стекла (glassmorphism) и адаптивный дизайн.

## Технологический стек

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Библиотеки**: [PapaParse](https://www.papaparse.com/) для парсинга CSV, [ExcelJS](https://github.com/exceljs/exceljs) для экспорта XLSX, [FileSaver.js](https://github.com/eligrey/FileSaver.js/) для сохранения файлов.
- **Backend (на выбор)**:
  - **Node.js (`server.mjs`)**: Полнофункциональный сервер с поддержкой наблюдения за файлами (fs.watch) и SSE.
  - **Python (`server.py`)**: Легковесный HTTP-сервер для статики.

## Структура проекта

- `index.html` — Основной файл приложения (интерфейс + логика).
- `server.mjs` — Сервер на Node.js.
- `server.py` — Сервер на Python.
- `start.command` — Скрипт для быстрого запуска сервера на macOS.
- `Open_Service.webloc` — Ярлык для быстрого открытия сервиса в браузере.
- `Directtext_dush_kab.csv` — Пример данных (объявления для душевых кабин).
- `Promt_Text_Direct/` — Директория с инструкциями, регламентами и системными промптами для работы с LLM.

## Как запустить

### Быстрый запуск на macOS

Просто дважды кликните по файлу `start.command`. Он запустит сервер (Node.js или Python) и автоматически откроет страницу `http://127.0.0.1:5511` в браузере.

### Вариант 1: Node.js (рекомендуется)

Обеспечивает работу функции «Живое обновление».

```bash
node server.mjs
```

После запуска откройте [http://127.0.0.1:5511](http://127.0.0.1:5511).

### Вариант 2: Python

Обычный сервер без поддержки SSE.

```bash
python3 server.py
```

После запуска откройте [http://127.0.0.1:5511](http://127.0.0.1:5511).

## Использование

1. Запустите сервер (например, через `start.command`).
2. Откройте приложение в браузере (через ярлык `Open_Service.webloc` или по ссылке `http://127.0.0.1:5511`).
3. Нажмите **«Загрузить»** и выберите ваш CSV-файл или просто перетащите его в окно браузера (Drag-and-Drop).
4. Редактируйте тексты. Следите за колонками лимитов (красный цвет сигнализирует о превышении).
5. Нажмите **«Экспорт для клиента»** для сохранения красиво оформленного XLSX-отчета или **«Сохранить в файл»** для сохранения новой версии CSV-файла (требуется File System Access API).
