# Y Direct Editor

Инструмент для удобного редактирования и визуализации CSV-файлов объявлений Яндекс Директ.

## Обзор
Проект представляет собой веб-приложение, которое позволяет загружать таблицы в формате CSV, редактировать их в реальном времени, отслеживать лимиты символов для заголовков и описаний, а также сохранять изменения обратно в файл.

## Основные возможности
- **Интерактивная таблица**: Редактирование текстовых полей прямо в браузере.
- **Контроль лимитов символов**:
  - Заголовок 1: до 56 символов.
  - Заголовок 2: до 30 символов.
  - Описание: до 81 символа.
  - Автоматический подсчет использованных символов и отображение остатка лимита.
- **Управление строками**: Возможность дублировать («Копировать») или удалять строки (с подтверждением).
- **Функции поиска и сортировки**: Быстрая фильтрация данных и сортировка по любому столбцу.
- **Быстрое копирование**: Отдельные кнопки для копирования содержимого ячеек в один клик.
- **Живое обновление (Live Update)**: При использовании Node.js сервера изменения в CSV-файле на диске автоматически отображаются в интерфейсе через Server-Sent Events (SSE).
- **Современный UI**: Темная тема, эффекты стекла (glassmorphism) и адаптивный дизайн.

## Технологический стек
- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Библиотеки**: [PapaParse](https://www.papaparse.com/) для парсинга и генерации CSV.
- **Backend (на выбор)**:
  - **Node.js (`server.mjs`)**: Полнофункциональный сервер с поддержкой наблюдения за файлами (fs.watch) и SSE.
  - **Python (`server.py`)**: Легковесный HTTP-сервер для статики.

## Структура проекта
- `index.html` — Основной файл приложения (интерфейс + логика).
- `server.mjs` — Сервер на Node.js.
- `server.py` — Сервер на Python.
- `Directtext_dush_kab.csv` — Пример данных (объявления для душевых кабин).

## Как запустить

### Вариант 1: Node.js (рекомендуется)
Обеспечивает работу функции «Живое обновление».
```bash
node server.mjs
```
После запуска откройте [http://127.0.0.1:4567](http://127.0.0.1:4567).

### Вариант 2: Python
Обычный сервер без поддержки SSE.
```bash
python3 server.py
```
После запуска откройте [http://127.0.0.1:4567](http://127.0.0.1:4567).

## Использование
1. Запустите сервер.
2. Откройте приложение в браузере.
3. Нажмите **«Загрузить»** и выберите ваш CSV-файл или просто перетащите его в окно браузера (Drag-and-Drop).
4. Редактируйте тексты. Следите за колонками лимитов (красный цвет сигнализирует о превышении).
5. Нажмите **«Сохранить в файл»** (требуется поддержка File System Access API в браузере) или **«Экспорт»** для скачивания новой версии файла.
