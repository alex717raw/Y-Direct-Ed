# Как быстро собрать нишевые списки в интернете (RU)

Цель: найти 3–7 источников и вытащить **кандидаты** минус-фраз/нерелевантных интентов для вашей ниши.

## Что искать

1) **Универсальные минус-слова** для Яндекс Директ (как «скелет»).
2) **Нишевые минус-слова** (по вашему товару/услуге).
3) **Смежные интенты** (запчасти/ремонт/DIY/обучение/бесплатно/бу/бэу/опт и т.п.).
4) **Словари комплектующих/материалов/видов работ** (чтобы точнее минусовать).

## Шаблоны запросов для поиска

Подставляй: `{ниша}`, `{товар}`, `{услуга}`, `{город}`.

- `минус слова {ниша} яндекс директ`
- `минус фразы {ниша} директ`
- `минус слова {товар} купить`
- `ключевые слова {ниша} wordstat`
- `семантическое ядро {ниша} пример`
- `запчасти {товар} список`
- `ремонт {товар} запросы`
- `{товар} своими руками запросы`
- `{товар} инструкция запросы`
- `{товар} комплектующие названия`
- `{товар} стекло для` (если минусуешь аксессуары)
- `{товар} запчасти для` (если минусуешь аксессуары)

## Как фильтровать найденное

1) Убери все, что противоречит вашему офферу и воронке (например, *отзывы* могут быть целевыми).
2) Дедуплицируй по смыслу (не плодить варианты одной и той же идеи).
3) Для фраз со стоп-словами (*для/из/с/без/по/на*) помечай кандидаты на оператор `+`.
4) Выдели 10–30 самых «опасных» мест, где минусование может отсечь целевое, и проверь на примерах запросов.

## Минимальный стандарт качества (чеклист)

- Есть универсальный слой (но адаптирован).
- Есть нишевой слой, найденный вне кампании (интернет/словари).
- Есть слой из контента сайта (категории/модели/условия/ограничения).
- Операторы `+` и `[]` использованы осознанно, а не «везде подряд».
