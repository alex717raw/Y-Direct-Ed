# Минус-фразы для Яндекс Директ

Цель: получить **готовый, проверенный список минус-фраз** (кампания/группа/ключ), который:
- исключает явно нерелевантные интенты;
- не «съедает» целевые запросы из-за стоп-слов/порядка слов/словоформ;
- укладывается в лимиты Директа (в т.ч. ≤ 7 слов на одну минус-фразу).

## Дефолты (как делать, если пользователь не уточнил)

- Уровень: **на кампанию**, и **на группы** только при явной разнице оффера/категорий/моделей между группами.
- Прогревные запросы: **минусовать**, но **выводить отдельным списком**.
- Формат выдачи: **через запятую для вставки** (без ведущих `-`, если не попросили иначе).
- Источник истины по ассортименту/услугам: **контент сайта** (если на сайте не указано — считаем, что не продается/не делается). При этом не пытайся «заминусовать весь мир» — добавляй только универсальные и нишевые отсечения, которые реально встречаются в семантике.

## Входные данные (обязательно собрать)

1) **Файл с текстами объявлений** (CSV/TSV/TXT/экспорт генератора; если XLSX — сначала экспортируй в CSV) — заголовки, описания, быстрые ссылки, уточнения, названия групп.
2) **Сайт/лендинг** — URL(ы) или сохраненная HTML-страница/текст (если нет доступа к сайту из окружения).
3) **Интернет-источники**:
   - универсальные списки минус-слов/минус-фраз;
   - нишевые списки (ключевые слова/минус-слова) по вашей тематике.

Если нет доступа к интернету/сайту: попроси пользователя прислать (а) экспорт текста с сайта, (б) 2–5 ссылок/вставок списков, (в) список ключевых слов конкурентов/Вордстата.

## Быстрый старт (механика)

1) Извлеки контекст кампании из файла объявлений и сайта:
   - Запусти `scripts/extract_context.mjs` и получи `context.md`.
2) Собери кандидаты минус-фраз:
   - Начни с универсального списка: см. `references/universal-negative-candidates.ru.md`.
   - Дособери нишевые кандидаты из интернета: см. `references/web-research-queries.ru.md`.
   - Адаптируй под кампанию по `context.md` и содержанию сайта (оставь только то, что реально нерелевантно для оффера с сайта).
3) Проставь операторы и проверь «опасные места»:
   - Стоп-слова (`+`), словоформы (`!`), порядок слов (`[]`), «точность по количеству слов» (`" "`).
4) Проверь лимиты и дубли:
   - Запусти `scripts/validate_minus_phrases.mjs` на итоговом файле.
   - Валидатор дополнительно ловит типовые ошибки ввода в Директ/Коммандер: запрещённые символы (например, `/`), точку `.` вне десятичных дробей, некорректный `+`/`!` (должны быть префиксом слова: `+для`, `!москву`).
5) Сформируй строку «вставить в Директ»:
   - (опционально) Прогони через `scripts/format_minus_phrases.mjs`, чтобы получить один ряд через запятую и отдельный список прогрева.

## Как собирать минус-фразы (процесс)

### 1) Сформируй «рамки релевантности»

Сформулируй из сайта и файла объявлений в 5–15 пунктах:
- **что продаем / делаем** (товары, услуги, гео, ценовой сегмент, условия) — только то, что явно следует из контента сайта;
- **чего нет в оффере** (смежные направления/товары/услуги), но не пытайся перечислить всё — дальше ты возьмешь это из универсальных и нишевых «конфузеров».

Эти рамки — главный фильтр для универсальных и нишевых списков.

### 2) Универсальные минус-фразы (скелет)

Возьми универсальные кандидаты из `references/universal-negative-candidates.ru.md`, но:
- не добавляй «на автомате» спорные слова (например, *отзывы*, *обзор*, *форум*), если они могут быть частью прогрева;
- учитывай модель бизнеса (для B2B *оптом/прайс* может быть целевым).

### 3) Нишевые минус-фразы (под кампанию)

Обязательно используй 3 источника одновременно:
- файл объявлений (словарь оффера и ограничений);
- сайт (категории, модели, бренды, «не делаем», условия);
- интернет (словари смежных/нерелевантных интентов и «соседние» товары).

Правило «сайт = ассортимент»: если сущность/категория/услуга **не встречается на сайте**, считай ее **кандидатом на минусование**, но добавляй в минус-фразы только если:
- она типично пересекается с вашей нишей (нашлось в интернет-списках/семантике/Wordstat);
- или уже видна в текстах объявлений / текущей семантике;
- или всплывает как «смысловая подмена» (см. ниже про предлоги и порядок).

Паттерны, которые почти всегда дают нишевые минус-фразы:
- **запчасти / комплектующие / расходники** (если вы продаете не их);
- **ремонт / сервис / устранение неисправностей** (если вы продаете новое/установку);
- **инструкции / как сделать / своими руками / чертеж** (если вам нужен «горячий» спрос);
- **бу/бэу / авито / разборка** (если продаете новое);
- **скачать / фото / картинки / видео** (если продаете товар/услугу, а не контент).

### 4) Операторы (обязательно)

Используй операторы **в минус-фразах**: `+`, `!`, `[]`, `" "`.

Ключевой принцип: фиксируй то, что меняет смысл.

- **Стоп-слова `+`**: фиксируй предлоги/частицы, если без них минус-фраза начнет «резать» целевые запросы.  
  Пример: добавь минус-фразу `стекло +для кабины` (аксессуар), но не минусуй `кабина из стекла` (материал/товар).
- **Словоформа `!`**: фиксируй, если важна конкретная форма слова (падеж/число/время).
- **Порядок слов `[]`**: фиксируй, если порядок критичен (особенно в паре с предлогами).  
  Пример: `[стекло +для кабины]`.
- **Кавычки `" "`**: используй, если нужно «сузить» минусование по количеству слов (требуется аккуратная проверка на примерах).

#### Типовой «нюанс» (смысловая подмена предлогами)

Ищи конструкции, где **ваш продукт** становится «атрибутом» чужого продукта/темы:
- целевое: `дрова +для бани` (покупают дрова);
- нецелевое: `баня +на дровах` (ищут баню/про баню; дрова — лишь атрибут).

Практика:
- смотри в `context.md` блоки `X + preposition + Y trigrams` и `Preposition bigrams`;
- выписывай 10–30 таких конструкций вокруг главных слов оффера и решай, что минусовать;
- фиксируй предлоги оператором `+`, чтобы различать смысл.

### Частые ошибки (чтобы не ломать сохранение в Коммандере)

- Не используй `/` (например, пиши `бу` / `бэу` / `бывший в употреблении`, а не `б/у`).
- Не используй точку `.` в доменах/брендах (пиши `battle net`, а не `battle.net`; точка допустима только в десятичных дробях типа `1.5`).
- Не ставь `+` в конце слова/числа (например, `18+` — ошибка; используй `18`, `для взрослых`).

## Формат результата

Выдай 3 блока:
1) **Минус-фразы на кампанию** (универсальные + общие нишевые).
2) **Минус-фразы на группы** (только если группы реально различаются по офферу/моделям/условиям).
3) **Прогрев (минусовать, но отдельным списком)** — *отзывы/обзор/форум/сравнение/как выбрать/инструкция/своими руками/чертеж/схема/фото/видео/скачать* и т.п.

Всегда добавляй:
- список «спорных» минус-фраз (требуют подтверждения);
- 5–10 примеров запросов, которые ты защищаешь от случайного отсечения (особенно вокруг `+` и `[]`).

Формат для вставки в Директ: одна строка **через запятую**.

## Файлы в этом скилле

- `scripts/extract_context.mjs` — извлечь тексты из файла объявлений/сайта и собрать `context.md`.
- `scripts/validate_minus_phrases.mjs` — проверить лимиты/дубли/количество слов.
- `scripts/format_minus_phrases.mjs` — привести список к строке «через запятую», дополнительно выделить прогревные фразы.
- `references/universal-negative-candidates.ru.md` — универсальные кандидаты (нужна адаптация).
- `references/web-research-queries.ru.md` — как быстро собрать нишевые списки в интернете.
