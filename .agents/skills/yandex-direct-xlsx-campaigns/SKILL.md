# XLSX-кампании Яндекс Директ

Собирай файлы импорта строго через шаблон:
- `assets/direct-commander-template.xlsx`

Используй его всегда как базу для листа `Export` и колонок `A:N`.

## Жесткие правила

1. Не удаляй колонки из шаблона и не меняй их порядок.
2. Если пользователь просит заполнить только часть полей (например, только тексты), оставляй остальные колонки пустыми строками, но в файле они должны оставаться.
3. Заполняй только явно запрошенные поля. Не додумывай значения в незапрошенные колонки.
4. Для генерации XLSX используй `scripts/build_direct_xlsx.mjs`.

## Быстрый workflow

1. Сформируй JSON с массивом строк (`rows`), где каждая строка — объект.
2. Для нужных полей задай значения, для остальных не задавай ничего (скрипт сам поставит пустые строки).
3. Запусти:

```bash
node scripts/build_direct_xlsx.mjs \
  --input /path/to/rows.json \
  --output /path/to/direct-import.xlsx
```

4. Верни пользователю путь к готовому XLSX.

## Формат входного JSON

Допустимы два формата:
- объект: `{ "rows": [ ... ] }`
- массив: `[ ... ]`

Каждая строка может быть:
- объектом с русскими названиями колонок;
- объектом с alias-ключами (`group_name`, `phrase`, `title1`, `title2`, `text`, `url`, `region`, `bid` и т.д.);
- массивом из 14 значений в порядке колонок `A:N`.

Пример (когда нужны только тексты и ничего больше):

```json
{
  "rows": [
    {
      "title1": "Подберем душевую кабину под ваш размер",
      "title2": "Монтаж за 1 день",
      "text": "Подбор, доставка и установка под ключ. Оплата по факту."
    }
  ]
}
```

Скрипт создаст строку с заполненными колонками `E:F:G`, остальные колонки будут пустыми, но сохранятся.
