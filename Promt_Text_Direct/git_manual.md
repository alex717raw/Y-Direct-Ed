# Git Workflow для безопасной разработки

## Шаг 1: Подготовка к эксперименту

`git checkout -b название-версии`
(Создаем новую ветку. Теперь можно ломать всё, основной код в безопасности).

## Шаг 2: Сохранение промежуточных итогов

`git add .`
`git commit -m "Описание того, что мы изменили"`
(Это «точка сохранения» в игре).

## Шаг 3: Отправка в облако (на GitHub)

`git push origin название-версии`
(Твоя новая ветка теперь видна на GitHub, её можно посмотреть там).

## Шаг 4: Если всё работает — «Внедряем»

1. `git checkout main` (Возвращаемся на главную ветку)
2. `git merge название-версии` (Вливаем изменения)
3. `git push origin main` (Обновляем GitHub)

## Шаг 5: Если всё сломалось — «Откатываемся»

`git checkout main`
(Просто возвращаемся на главную ветку. Экспериментальная ветка останется лежать отдельно, она не мешает).
